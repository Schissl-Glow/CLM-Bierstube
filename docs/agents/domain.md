# Domain docs

Das Projekt verwendet einen gemeinsamen Dokumentationskontext.

Vor fachlicher Analyse vorhandenes GLOSSARY.md und relevante Entscheidungen
unter docs/adr/ lesen. Ihre Begriffe verwenden und Widersprüche offenlegen.

Fehlende Glossar- oder ADR-Dateien blockieren die Arbeit nicht.
Sie entstehen erst bei tatsächlich geklärten Begriffen oder Entscheidungen
innerhalb eines freigegebenen Auftrags.

ARCHITECTURE.md bleibt die bestehende Architekturreferenz.
