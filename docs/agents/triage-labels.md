# Triage labels

| Rolle | Label |
| --- | --- |
| Erste Bewertung erforderlich | needs-triage |
| Weitere Informationen erforderlich | needs-info |
| Bereit für Agent-Bearbeitung | ready-for-agent |
| Menschliche Bearbeitung erforderlich | ready-for-human |
| Keine Umsetzung vorgesehen | wontfix |

ready-for-agent ersetzt keine ausdrücklich erforderliche Freigabe.
