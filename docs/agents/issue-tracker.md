# Issue tracker

Tickets und Spezifikationen liegen in GitHub Issues unter
Schissl-Glow/CLM-Bierstube.

GitHub-CLI-Aufrufe mit --repo Schissl-Glow/CLM-Bierstube ausführen,
damit upstream nicht versehentlich als Ziel verwendet wird.

Tickets über gh issue view/list lesen.
Anlage, Kommentare, Bearbeitung und Schließen nur im freigegebenen Auftrag.
Mehrzeilige Texte über --body-file übergeben.

PRs as a request surface: no.

Veröffentlichte Inhalte sind im derzeit öffentlichen Repository sichtbar.
SavedVariables und persönliche Daten bleiben lokal.
